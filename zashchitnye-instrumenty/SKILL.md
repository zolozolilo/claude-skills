# Защитные инструменты

## Суть
Защита, которая сама ломает работу или молча открывает настоящие данные, хуже, чем её отсутствие. Правила 1–5 — про режимы и хуки, 6–9 — про сторожей с необратимыми действиями (circuit breaker, жизненный цикл флагов), 10–13 — про сторожа и защиту файлов.

## Правила
1. **Умолчание — всегда безопасный режим.** Новый режим — только по явному ключу или после проверки, что сборка его умеет; иначе прежний безопасный путь. Меняешь общий инструмент — сразу сказать всем, кто им пользуется.
   Урок: скрипт запуска перевели на «без подмены папки данных» по умолчанию — любая сборка без поддержки переменной с папкой данных открыла бы настоящую базу. Поймали до прогона.
2. **Запрещающий хук оставляет выход.** До включения — список «чем агент закончит работу» (сдать отчёт, отправить сообщение, записка, коммит) и тест на каждый выход. Глобальный хук задевает все сессии — первые минуты после включения смотреть его журнал.
   Урок: хук бюджета токенов запретил и сдачу отчёта — агент не мог закончить; задел агентов чужой сессии. Поймали по журналу хука через 2 минуты.
3. **«Поведение по умолчанию не изменилось» — только с тестом на режим ПО УМОЛЧАНИЮ** (без переменной, без ключа, без флага). Тест пишет приёмщик одновременно со строителем.
4. **Массовая замена поиском — файл-источник отдельно.** Заменил `X` на `Обёртка.X` по всему коду → открыть саму `Обёртку` глазами: не вызывает ли она теперь себя. grep «вне обёртки = 0» внутрь неё не смотрит.
   Урок: все обращения к системной папке заменили на обёртку, вместе с запасным путём внутри самой обёртки → бесконечная рекурсия → вылет у пользователя без песочницы.
5. **У каждого защитного инструмента — выключатель** (env-переменная, файл-флаг, ключ скрипта), записанный рядом с инструментом. Проверка: включён на обычной работе — работа идёт; выключен — поведение как до него.
6. **У защиты есть владелец и срок** (в META: `owner`, `expires` ≤ 1 года). После срока — тихий режим: не действует необратимо, пишет в журнал, ждёт продления. Выключатель остаётся навсегда, срок продлевается осознанно.
7. **Необратимое — только после второго, отдельного чтения** (как `for:` в алертах Prometheus: условие должно продержаться, а не мигнуть) и **в пределе действий за проход** (`max_actions`, предел на час тоже). Подозрительный снимок — неполный (много «нет данных») или «беда» у слишком большой доли — отвергается целиком: решает человек. Предел — единицы или десятки, не тысячи; больше — только с явного «да» человека.
8. **Каждый отказ — строка в журнал** с причиной и списком объектов (иначе защита «просто не работает» незаметно). Журнал смотреть после включения и раз в сутки.
9. **Контракт до кода.** Нового сторожа/хука начинай с копии `shablon/`: перепиши только `adapter.py`, прогони `python -m pytest` — красный до кода, зелёный после. 9 проверок: выход, владелец и срок, тишина после срока, предел, второе чтение, журнал, отказ человека главнее, подтверждение только новым срезом, повтор при временном отказе и сообщение владельцу. Ещё в шаблоне: записанные снимки (replay); добавь Hypothesis `@given` на игрушке, а у сторожа с памятью (счётчики подряд) — `RuleBasedStateMachine` с `@invariant`. Мутанты в `test_primer_storozh.py` доказывают, что контракт не зелёный вхолостую.
10. **Отказ человека главнее повтора автоматики.** Сторож помнит «до» и «отмена»: если человек отменил действие или поднял порог на минуту, автомат не повторяет то же самое со следующим проходом; действует только от изменения, которое сделал виновник. Тест: `check_human_refusal_wins`.
    Урок: человек поднял порог на несколько минут и отменил действие сторожа — без этого правила сторож повторил бы его на следующем проходе.
11. **Подтверждение — только НОВЫМ срезом.** Два одинаковых чтения подряд (тот же снимок, перезапуск службы, кэш) — это одно; второе чтение — отдельный запрос через паузу (часы, а не секунды, если данные меняются редко) после старта/выкладки. Тест: `check_independent_confirm`.
    Урок: правило «пусто два раза подряд» засчиталось из-за перезапуска службы — запись выключена как закончившаяся.
12. **Временный отказ внешней системы — повтор сам; провал — человеку.** «Сервис не ответил» — не окончательный отказ: срочное повторять до успеха (`retries` в META), после последней попытки — строка в журнал, сообщение владельцу и честная надпись на экране; сторож не считает объект «занятым» по неудавшейся заявке. Тест: `check_urgent_retry_and_alert`.
    Урок: заявка во внешний сервис зависла в статусе «ждём», повтора нет — несколько часов действие считалось сделанным, а экран писал «выполняется».
13. **Защитный инструмент пишет файлы безопасно.** Данные, на которые опираются другие процессы (журнал, снимок, копия), — запись `encoding='utf-8'`, во временный файл и `os.replace`, права как у соседей; проверка — прогнать потребителя после записи. Хуки на опасные команды — только «ask» с выходом и журналом, глушат собственный сбой, правила проверяются прогоном по прошлым командам на ложные срабатывания.

## Чек-лист перед «готово»
- [ ] без ключей и переменных инструмент делает безопасное (тест)
- [ ] у запрета есть выход, и тест на выход зелёный
- [ ] тест на режим по умолчанию написан до вердикта «как раньше»
- [ ] после массовой замены файл-источник прочитан глазами
- [ ] выключатель есть, проверен, записан рядом с инструментом
- [ ] глобальный хук/сторож — журнал первых минут просмотрен
- [ ] всем, кто пользуется инструментом, сказано, что поменялось
- [ ] `shablon/` скопирован, контрактный тест зелёный, красный был до кода
- [ ] владелец и срок записаны; предел действий и второе чтение — в тесте
- [ ] подозрительный снимок отвергается; каждый отказ в журнале
- [ ] отказ человека учтён (тест), подтверждение — только новым срезом (тест)
- [ ] временный отказ внешней системы повторяется; провал дошёл до человека, а не только в журнал
- [ ] новое правило хука прогнано по прошлым командам: ложных срабатываний нет, свой сбой — молчание

## Красные флаги
| Мысль | На деле |
|---|---|
| «Новый режим лучше — сделаю его по умолчанию» | Старые сборки его не умеют → настоящие данные |
| «Запрещу всё, кроме нужного» | Сначала список выходов: отчёт, сообщение, коммит |
| «Агент пишет: без подмены — как раньше» | Без теста на режим по умолчанию это слова |
| «grep показал 0 вне обёртки — всё заменено» | Внутри обёртки замена могла сделать рекурсию |
| «Выключатель не нужен, инструмент простой» | Сломает работу ночью — нечем выключить без выпуска |
| «Сторож видит 0 — значит, беда» | Один снимок мог быть неполным: второе чтение и предел |
| «Срок не нужен, пусть работает всегда» | Забытая защита ломает работу годами: срок и владелец |
| «Человек отменил, но сторож видит ту же беду — пусть пришлёт снова» | Отказ человека главнее: автомат не повторяет отменённое |
| «Два нуля подряд — подтверждено» | Если это тот же срез (перезапуск, кэш) — это один ноль |
| «Сервис не ответил — запишу в журнал и подожду» | Срочное повторять до успеха и сообщить человеку, иначе часы потерь |
