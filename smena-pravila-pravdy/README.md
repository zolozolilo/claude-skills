# smena-pravila-pravdy

Скилл Claude Code: перед сменой источника правды (или поля, ключа JSON, метода, используемого в нескольких местах) найти ВСЕХ, кто пишет и читает, и пройти круг проверок до выкладки. Три скрипта делают механическую часть.

| Файл | Что делает |
|---|---|
| `SKILL.md` | Круг из 9 пунктов, отговорки, красные флаги |
| `kto_pishet.py` | Кто пишет и читает имя по всем корням (`-k`); варианты snake/camel/Pascal, недостижимый код, динамический доступ; `--json` |
| `reestr_polon.py` | Каждый файл папки назван в реестре (список секций, скрипт выкладки) |
| `css_bez_prefiksa.py` | Селекторы CSS вне приставки раздела (`--diff` — только добавленное) |
| `tests/` | pytest-тесты скриптов |

Установка: `cp -r smena-pravila-pravdy ~/.claude/skills/`
Нужно: Python 3.9+ (stdlib), git для `--diff`; ripgrep (`rg`) по желанию. Тесты: `python -m pytest -q`.
