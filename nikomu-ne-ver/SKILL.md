# Никому не верь

## Суть
Любое утверждение пользователю — только после проверки **свежими данными из первоисточника** и **смысла числа**. Отчёт агента, свои прошлые цифры, заметка, подпись на экране, память — это подсказки, где искать, а не доказательства.

**Нарушить букву — нарушить дух.** «Я же почти проверил» = не проверил.

## Перед каждым ответом с цифрой или вердиктом

| Проверка | Как | Типичный провал |
|---|---|---|
| **Свежесть** | Новый запрос к источнику прямо сейчас; в ответе — время среза | повторил цифры получасовой давности — «не хватает 100», реально ~6 |
| **Смысл числа** | Отвечает ли число на вопрос? Что уже учтено, что посчитано дважды | «новые + в работе − на полке», а часть уже выдана |
| **Текущее состояние** | Позиция/сервис ещё в том состоянии, о котором речь? | тревога по записям, которые уже отключены |
| **Неизвестно ≠ нет** | «нет данных» / пустая клетка — выяснить причину до слов «нет» | «нет заказов», а у программы нет папки / старое имя |
| **Второй источник** | Сверить с независимым: другая система, другой отчёт | два разных «нет» — по разным причинам |
| **Время событий** | Только из журнала службы или переписки (с часовым поясом), до минуты | «около 15:30» вместо 15:41 |
| **Код на данных** | Причину называть после прогона кода/запроса на реальных данных (только чтение) | диагноз «нет остатков», а была пара |
| **Упавшая / пустая проверка** | Код выхода и вывод — до слов: падение, таймаут, пусто = «не знаю», не «нет» и не «всё хорошо» | «обновлений нет» — утилита упала |
| **Чей ответ** | В ответе метка отвечавшего (версия, машина, счётчик); свои копии клиента закрыть | «связь есть» ответила своя копия программы |
| **«Нет» с контролем** | Поиск сначала на заведомо существующей записи; проверить форму данных (`type`, ключи) | «заявок: 0» — а это словарь, не список |
| **Сравнение A↔B** | Одинаковые условия (нагрузка, путь, данные); «0 против 0» первым; свежесть источников — отдельно | «+900 тыс.» — артефакт замера; «выключатель хуже» — окна с разной нагрузкой |
| **Права / видимость** | Выдачей под той же учёткой, не чтением файла прав | «администратор» — флажок, а не права |
| **Оценка до замера** | Срок/ускорение — после замера на малом (1 шт., 3 кадра), до него «проверю»; цена платного сервиса — ×1,5 и «при повторах до N»; «облако/бесплатно» — после пробы | $0,65 → $0,96; «облачный» агент оказался не бесплатным |
| **Готово по косвенному** | Завершение процесса + проверка самого артефакта (ffprobe, открыть); не размер файла и не журнал | ролик «готов», звук не слушали |
| **Поле / единица** | Поле — в живом образце (`pole_est.py`); тест — настоящей записью, не выдуманной | поле выдумано, тест зелёный |
| **Необратимое на устройстве** | Сначала содержимое (`Get-Disk`, `Get-Partition`, `Get-Volume`, `lsblk`: что занято, чьё), источник факта вслух; драйвер/устройство вслепую не трогать | «пустая система» — Restore стёр бы диск; `PasswordRequired: False` ≠ «пароля нет» |

## Одной командой (скрипты в этой папке: `python ~/.claude/skills/nikomu-ne-ver/<имя>`)
- `srez.py [--raza 2 --pauza 60] [--ozhidat МЕТКА] [--ishchu X --kontrol Y] -- <команда>` — время среза (МСК; поправить `MSK` в файле под свой пояс), двойное чтение (md5 с паузой), метка отвечавшего, «нет» только с положительным контролем; код 3 = «НЕ ЗНАЮ».
- `pole_est.py <поле> --obrazec снимок.json` — есть ли поле в живой записи; нет — покажет настоящую схему.
- `priyomka_agenta.py --repo <репо> --base <основная ветка> [--testy вывод.txt --kod-testov N]` — коммиты, «код без теста», «не закоммичено», зелёный = failed 0 и skipped 0.

## Причина («почему так») — только с доказательством
Догадка звучит как причина, поэтому причина пользователю — только в такой форме:
> **Причина:** … **Доказано:** строка журнала / вывод команды (время, откуда). **Отброшено:** другая версия — чем. **Не проверено:** …

- Нет строки «Доказано» — это **гипотеза**: так и сказать, плюс какой проверкой подтвердим и за сколько минут.
- Сначала прочитать ВСЕ строки журнала и окна за момент симптома, потом версия.
- «Не A, значит B» — гипотеза, пока B не увиден на данных.
- Подтверждать там, где симптом: окружение пользователя, боевая версия — не своя сборка.
- Одна гипотеза за раз: «думаю X, потому что Y» → самая маленькая проверка → да/нет. Две неверные версии подряд — стоп догадкам: данные на входе и выходе каждого звена, потом третья (superpowers `systematic-debugging`).
- «Починено» = исходный симптом не повторяется на том же входе, а не «код поменял».
- Перед починкой симптома найти исходное задание или договорённость (переписка, тикет), а не только экран.
- «Пусто / 0» — не поломка и не «есть»: сначала журнал службы, нарезка страницы и отборы.

## Отчёт агента
1. `git log`/`git diff` — что реально изменено; пересобрано ли. Одной командой — `priyomka_agenta.py`.
2. Тесты прогнать **самому**; новые тесты — убедиться, что падают без правки.
3. Числа «на проде» из отчёта пересчитать своим свежим запросом и проверить смысл (таблица выше).
4. Агент копировал данные продакшена на машину? — удалить, сказать.
5. Только потом — «можно выкладывать».

## После выкладки
Проверить **на работающем коде** ту самую позицию, ради которой правка (не «health ok»). Написать пользователю, что проверено, а что нет. «Выложено» — по итоговой строке скрипта выкладки и повторной проверке версии через минуту (`srez.py --raza 2 --pauza 60 --ozhidat <версия>`): «исправление уже на проде» бывает за секунды до отката. Чужую выкладку подтверждает сумма файлов (md5), не перезапуск службы.

## Красные флаги — стоп, проверить
- «Агент же написал, что…»
- «Я это уже считал»
- «На экране так написано»
- «Число сошлось с живыми данными» (а формула верна?)
- «Скорее всего ещё так / уже иначе»
- «Нет данных — значит нет»
- Проверка упала или вернула пусто, а в ответе «нет» / «всё хорошо»
- В причине «скорее всего», «наверное», «похоже», «раз не то — значит это»
- «У меня воспроизводится / не воспроизводится» — окружение не пользователя и не прода
- Пользователь переспрашивает «реально?», «почему так?», «старые данные?» — значит, проверка пропущена.

## Отговорки

| Отговорка | На деле |
|---|---|
| «Пользователь торопит» | Неверная цифра стоит дороже минуты запроса |
| «Тесты агента зелёные» | Тесты проверяют то, что агент понял, а не то, что нужно пользователю |
| «Свежий запрос — те же цифры» | Тогда это 30 секунд, и в ответе честное время среза |
| «Это мелочь» | Из «мелочей» выходят несуществующие заказы и ложные тревоги |
| «Причина очевидна, журнал читать долго» | Часы догадок и три версии за вечер — дольше любого журнала |
