# nikomu-ne-ver

Скилл Claude Code «никому не верь»: число, вердикт, «готово» и причина бага называются только после своей свежей проверки; отчёт агента — подсказка, а не доказательство. Три скрипта делают проверки одной командой.

| Файл | Что это |
|---|---|
| `SKILL.md` | правило, таблица проверок, форма «Причина / Доказано / Отброшено», приёмка отчёта агента |
| `srez.py` | свежий срез: время, двойное чтение, метка отвечавшего, «нет» только с контролем |
| `pole_est.py` | есть ли поле в живом образце данных (JSON/JSONL/CSV) |
| `priyomka_agenta.py` | приёмка работы агента: git-факты, «код без теста», итог тестов |
| `tests/` | pytest-тесты скриптов |

## Установка
```
cp -r nikomu-ne-ver ~/.claude/skills/
```

## Что нужно
Python 3.10+ (только stdlib), git для `priyomka_agenta.py`, pytest для тестов: `PYTHONUTF8=1 python -m pytest -q -p no:cacheprovider`.
