# Не наступать на грабли

## Суть
Каждая наша ошибка записана в файл уроков. Перед делом — найти записанные грабли по словам задачи и обойти их; после новой ошибки — записать, чтобы следующий не наступил. Хук делает первую половину сам: перед командой подкладывает подходящий урок, при старте сессии — выжимку главных правил (подключение — в README).

## Перед задачей (2 минуты, дёшево)
1. Поиск по словам задачи — модуль, файл, действие:
   ```
   python ~/.claude/skills/ne-nastupat-na-grabli/grabli.py pkill выкладка
   ```
   Файл уроков — `GRABLI_LESSONS` или `uroki.md` рядом со скиллом. Новое — сверху. Целиком файл читать, только если находка прямо про задачу.
2. По каждой подходящей находке — одна строка себе: «урок X → в этой задаче делаю Y».
3. **У правила несколько версий — верна последняя** (дата, пометка `[ИЗМЕНЕНИЕ]`). Старая версия в заметке — тоже грабли.
4. Задание агенту — вставить подходящие уроки короткими строками прямо в текст задания и назвать файл по имени.

## После ошибки или поправки пользователя
Сразу дописать в файл уроков раздел `## заголовок`: **что** случилось → **почему** → **правило**. Те же грабли второй раз — правило в скилл, тест или сигнал хука (одна строка в `SIGNALS`).

## Пользователь написал «опять» / «я же просил» — повтор
1. Первым в ходе — короткий текст пользователю (признать повтор), не молчаливая работа.
2. Найти прежнее указание: `grabli.py --pamyat <слова>` (добавляет файлы `feedback_*.md` из папки `MEMORY_DIR`, только чтение).
3. В ответе назвать найденное указание и честно сказать, почему оно не сработало: не искал / текст не держит / правило узкое.
4. Второй повтор той же темы — не ещё одна строка текста, а автомат: хук, тест, обязательная строка в шаблоне задания.

## Красные флаги
- «Задача новая, уроков по ней нет» — сначала поиск, потом вывод
- «Помню, как правильно» — правило могли поменять
- «Тесты зелёные — значит, можно» — тесты не ловят всё
- Пользователь: «опять», «снова», «уже было» — поиск пропущен; найти урок и сказать, почему не сработал

| Отговорка | На деле |
|---|---|
| «Некогда, торопят» | Поиск — 1 команда; повтор ошибки — часы и откаты |
| «Прочитаю весь файл уроков» | Дорого и тонет главное — ищи по словам |
| «Записать урок потом» | Потом забудется; записывать сразу |
