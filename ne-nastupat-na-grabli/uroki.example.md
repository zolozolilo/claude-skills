# Уроки — ошибки и как не повторять

Формат: раздел «## заголовок», новые уроки — в конце файла. В тексте урока должны стоять слова из SIGNALS хука.

## pkill -f убивает лишнее

**Что случилось.** `pkill -f server` остановил и чужой процесс, в командной строке которого было слово server.
**Правило.** Перед `pkill -f` / `pgrep -f` — `pgrep -fa <шаблон>`: убедись, что совпал только нужный процесс; лучше убивать по PID.

## tar --exclude с неверным порядком ключей

**Что случилось.** Архив собрался с папкой, которую исключали: `--exclude` стоял после списка путей, и tar его проигнорировал.
**Правило.** Для `tar --exclude` ключи — до путей; после сборки сверить `tar -tf` на отсутствие исключённого.

## python -m pytest: No module named pytest

**Что случилось.** Тесты «не запустились» из-за другого интерпретатора, а не из-за кода; сказали «тесты зелёные» без прогона.
**Правило.** При `No module named pytest` — поставить зависимость в тот же интерпретатор (`python -m pip install pytest`); «зелёные» — только после реальной строки итога pytest.

## rsync живых данных без пробного прогона

**Что случилось.** `rsync --delete` в рабочую папку стёр свежие файлы.
**Правило.** Для rsync сначала `--dry-run`, без `--delete` по умолчанию, и копия перед записью.

## heredoc с обратным слэшем

**Что случилось.** Скрипт в heredoc потерял `\n` — оболочка разобрала слэши до интерпретатора.
**Правило.** Heredoc с обратными слэшами — только в кавычках (`<<'EOF'`); результат проверить выводом файла.
